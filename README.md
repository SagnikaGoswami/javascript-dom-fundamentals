# JavaScript DOM Fundamentals

## Overview

This repository contains basic JavaScript exercises focused on understanding and working with the Document Object Model (DOM).

The exercises explore how JavaScript interacts with HTML elements, handles user input, responds to events, and dynamically updates webpage content.

## Concepts Practiced

- Selecting HTML elements using `document.getElementById()`.
- Retrieving and processing user input.
- Converting string inputs into numbers using `Number()`.
- Handling user interactions through JavaScript functions and HTML event attributes.
- Dynamically updating webpage content using `innerHTML`.
- Modifying element styles through JavaScript.
- Exploring `document.activeElement` to identify the currently focused HTML element.

## Exercises

### 1. Basic Addition Using DOM (`index.html`)

A simple interactive webpage that accepts two numerical inputs, calculates their sum, and displays the result dynamically.

**Concepts:** DOM selection, input handling, type conversion, event handling, and dynamic content updates.

### 2. Identifying the Active HTML Element (`second.html`)

An exercise exploring the `document.activeElement` property to retrieve and display the tag name of the currently focused element.

**Concepts:** DOM properties, focus detection, event handling, and dynamic content updates.
